Fehler: 0 % trotz Medium / Füllstandsignal ausgeblendet

Korrekte Abgleichwerte, aber das echte Mediumecho liegt in der Ausblendung.

Kurzantwort

Ist das Füllstandsignal ausgeblendet, bleibt die Anzeige bei 0 %

Das Quellenbeispiel zeigt 0 % bei real etwa 10 %, obwohl Leer- und Vollabgleich korrekt sind. Ursache ist eine Ausblendung des Füllstandsignals; die Quelle nennt als Lösung, die Ausblendung zu löschen.

Ausblendung kontrolliert zurücksetzen: Vor dem Löschen aktuelle Kurve, Parameter und Tankzustand sichern. Danach Störechos und Mediumecho unter sicheren Prozessbedingungen neu bewerten.
